メモリー2枚/3枚の構成とseedから山札順を表示します。開始データを使う場合はseedと実デッキを自動で読み取れます。

メモリーデータ

各メモリーに userMemoryId と activeProduceCardIds が必要です。共通カードは baseProduceCards に順番どおり指定します（0枚なら空配列）。

01

ExamContestSituation → Stages → SelfSections/RivalSections → Player から Seed と ProduceCards を読み取ります。

      メモリー構成だけではカード順は一意になりません。開始時のPlayerに入るseedが必要です。開始データモードではそのseedを自動取得します。
