    01

    アイドルへの道 編成

    アイドルへの道のデッキは、選択メモリーの採用カード + MainのPアイドルのタイプに対応する基本カード2枚で構成します。

    自動追加される基本カード

    Pアイドルの examEffectType（好調 / 集中 / やる気 / 好印象 / 強気 / 全力）から現在のドル道仕様に対応する基本カード2枚を自動選択します。

    Pアイテム

    Pアイテムとアイドルへの道固有の応援・トラブル効果は、厳密な効果処理を接続してから適用します。

    02

    ターン単位カード循環シミュレーション

    毎ターン3枚を実際にドローし、カードを1枚使用するかスキップして次ターンへ進めます。通常カードは捨て札へ、「レッスン中1回」のカードは使用した場合だけ除外されます。山札が空なら、その時点の捨て札だけを同じ乱数状態の続きで再シャッフルします。カード効果そのものはこの画面では計算しません。

    履歴

      SEED

      実機の順番からseedを探索

      0 / 0枚

      アイドルへの道シミュで設定した編成を使い、実機で見えた3枚ずつの連続ドロー順から32-bit seed候補を逆算します。seed特定時は毎ターンスキップする前提なので、3枚の手札はそのまま捨て札へ移動します。山札が空の状態で次の1枚を引く瞬間に、その時点の捨て札だけをseedの続きで再シャッフルします。

      メモリーと採用カードを設定すると観測入力ボタンが表示されます。
